VoltGuard - third-party font software shipped in this directory
================================================================

The .woff2 files here are subsets / instances of the following open-source fonts.
They are generated by tools/build-assets.py (see that file for the exact sources and the pinned
commit / package versions). The copyright notice and licence information of each font is also kept
in the name table of every woff2 file.

Font Awesome Free 6.5.1  (fa-*.woff2 and css/fa-subset.css)
  Font Awesome Free by @fontawesome - https://fontawesome.com
  Icons: CC BY 4.0  - https://creativecommons.org/licenses/by/4.0/

  Copyright 2023 Fonticons, Inc.  Full terms: https://fontawesome.com/license/free

The fonts are used unmodified apart from subsetting (removal of unused glyphs and layout features)
and, for Inter, restriction of the variable axes (opsz fixed at 14, wght 400-900).
